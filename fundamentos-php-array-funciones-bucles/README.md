# Fundamentos PHP - Arrays, funciones y bucles

Bloque de ejercicios de fundamentos de PHP centrados en **arrays**, **funciones** y **bucles**.

La progresión va desde lo más básico (recorrer un array) hasta casos más cercanos a una necesidad real (catálogos, stock, presupuestos).

## Ejercicios

| # | Carpeta | Tipo de ejercicio |
|---|---------|-------------------|
| 01 | `ejercicio01-listaCompra` | Recorrido de arrays |
| 02 | `ejercicio02-verificador` | Comprobación de arrays |
| 03 | `ejercicio03-returnValues` | Funciones con retorno |
| 04 | `ejercicio04-buscadorArray` | Búsqueda en arrays |
| 05 | `ejercicio05-clasificacionNotas` | Clasificación con condicionales |
| 06 | `ejercicio06-clasificacionNotas` | Filtrado de arrays |
| 07 | `ejercicio07-catalogo-zapatillas` | Arrays asociativos |
| 08 | `ejercicio08-stockShop` | Arrays multidimensionales |
| 09 | `ejercicio09-filtroPresupuesto` | Filtrado por condición |
| 10 | `ejercicio10-precioMax` | Búsqueda del valor máximo |


## Cómo ejecutar

1. Coloca la carpeta dentro de `htdocs` (XAMPP) o `www`.
2. Arranca Apache.
3. Abre en el navegador el `index.php` del ejercicio, por ejemplo:

```
http://localhost/fundamentos-php-array-funciones-bucles/ejercicio01-listaCompra/index.php
```

Para ejecutarlos desde la terminal:

```bash
php fundamentals-php-array-funciones-bucles/ejercicio01-listaCompra/index.php
```

# Fundamentos PHP - Arrays, Funciones y Bucles

Ejercicios prácticos de fundamentos de PHP centrados en **arrays**, **funciones** y **bucles**.

## Estructura

```
fundamentos-php-array-funciones-bucles/
├── ejercicio01-listaCompra/      → Bucle for + función con arrays
├── ejercicio02-verificador/      → empty() + foreach
├── ejercicio03-returnValues/     → return + count()
├── ejercicio04-buscadorArray/    → in_array()
├── ejercicio05-clasificacionNotas/ → Condicionales + clasificación
└── ejercicio06-clasificacionNotas/ → Filtrado y creación de arrays
```

## Requisitos

- PHP 7.x o superior
- Apache (XAMPP, LAMP) o servidor local

## Cómo ejecutar

1. Coloca la carpeta dentro de `htdocs` (XAMPP) o `www`.
2. Inicia Apache.
3. Abre en el navegador:

```
http://localhost/fundamentos-php-array-funciones-bucles/ejercicio01-listaCompra/index.php
```

Cambia la ruta del ejercicio para probar los demás.
